Click the button. The server streams a multipart/mixed response. Each part has its own HX-Retarget and HX-Reswap headers.

This demo streams one part per second for about 20 seconds, so you can watch it in DevTools. A boundary finalizes the previous part, so each panel updates as the next part begins. The request indicator remains active until the final boundary closes the response.
